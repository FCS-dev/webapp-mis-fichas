# AGENTS.md — Mis Fichas WebApp

Pure vanilla HTML/CSS/JS webapp. No build tools, no package manager, no framework.

## Run

Open `index.html` directly in a browser. No dev server required.

## Entrypoints

- `index.html` — single HTML page, loads `css/style.css` and `js/script.js`
- `css/style.css` — styles (uses `content-box` box-sizing)
- `js/script.js` — application logic (currently empty skeleton)

## Conventions

- Locale: `es` (Spanish; UI text, comments, and commit messages should be in Spanish)
- No external dependencies or CDN scripts

## Testing

No test setup exists.
